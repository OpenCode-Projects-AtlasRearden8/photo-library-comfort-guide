# Photo Library Comfort Guide

A warm, plain-English manual for rescuing your camera roll — the monthly one-hour triage, exact duplicates versus near-dupes, albums you will actually keep, naming scans, cloud versus your own drive, sensitive photos handled carefully, printed books and gift frames, and retiring old phones safely.

Built for people with a full camera roll, a full life, and no interest in becoming a professional archivist. If attention, energy, or ADHD makes long projects hard, every chapter offers a low-energy path. Nothing here lectures; everything here helps.

## Quick start

You need Node.js 18 or newer. No dependencies, no accounts, no uploads — the whole project works offline.

```bash
npm run build   # build the static site into site/
npm test        # run the full test suite
npm run check   # build, then test
```

The build script (`scripts/build.js`) turns the Markdown into a standalone static site with navigation, anchors, printable worksheet styling, and print-friendly CSS. The Markdown engine it uses (`scripts/markdown.js`) is dependency-free and unit-tested.

This guide never asks for your photos, your accounts, or a network connection. The site is built locally from text files; no telemetry, no analytics, no cookies. The repository contains no secrets or personal data. Your camera roll stays exactly where you put it.
